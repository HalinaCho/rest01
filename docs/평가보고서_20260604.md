## 2. 기술 스택 평가

### 2-1. 아키텍처

| 항목 | 선택 | 평가 |
|---|---|---|
| 마크업 | HTML5 Semantic | ✅ 적절 — section/nav/footer 의미 태그 활용 |
| 스타일 | CSS3 + Custom Properties | ✅ 우수 — 팔레트 전환을 변수만으로 처리 |
| 스크립트 | Vanilla JS (ES6+) | ✅ 적절 — 프레임워크 미사용으로 경량 유지 |
| 배포 | GitHub Pages + Actions | ✅ 우수 — push만으로 30초 내 자동 배포 |
| 의존성 | Google Fonts, Font Awesome CDN | ⚠️ 외부 CDN 의존 (오프라인 취약) |

### 2-2. CSS 설계

```
css/
├── style.css          구조 전용 (색상 하드코딩 전무)
└── palettes/          색상 전용 (팔레트별 분리)
    ├── blue.css        ← 현재 기본값
    ├── purple.css
    ├── green.css
    ├── red.css
    └── teal.css
```

**강점:** CSS Custom Properties를 전면 도입하여 팔레트 파일 교체만으로 전체 색상 전환 가능.  
각 팔레트 파일에 라이트·다크 변수가 독립적으로 정의되어 유지보수 용이.
