| 역할 | 설명 |

| 파일 | Dark | Light |
|---|---|---|
| `blue.css` (기본) | `#1e3a5f` Dark Navy | `#60a5fa` Royal Blue |
| `purple.css` | `#3b1f6e` Dark Purple | `#c084fc` Lavender |
| `green.css` | `#14532d` Dark Forest | `#a3e635` 연두 |
| `red.css` | `#7f1d1d` Dark Crimson | `#fca5a5` Rose |
| `teal.css` | `#134e4a` Dark Teal | `#5eead4` Cyan |

다크모드: `@media (prefers-color-scheme: dark)` + `[data-theme="dark"]` 이중 지원.  
팔레트 선택·다크모드 상태는 `localStorage` 에 저장, 재방문 시 유지.
