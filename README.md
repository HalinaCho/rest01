# 개인 이력서 웹사이트

## 프로젝트 구조

```
rest01/
├── index.html          # 메인 페이지
├── css/
│   └── style.css       # 스타일시트
├── js/
│   └── main.js         # 인터랙션 스크립트
└── images/             # 이미지 폴더
    ├── profile.jpg     # 프로필 사진 (히어로 섹션)
    ├── about.jpg       # 소개 섹션 사진
    ├── project1.jpg    # 프로젝트 1 썸네일
    ├── project2.jpg    # 프로젝트 2 썸네일
    ├── project3.jpg    # 프로젝트 3 썸네일
    └── resume.pdf      # 다운로드용 이력서 PDF
```

## 콘텐츠 수정 방법

`index.html` 파일에서 아래 항목들을 실제 정보로 교체하세요:

- **이름**: `조 할리나` → 본명으로 변경
- **직책**: `웹 개발자 · UI/UX 디자이너` → 실제 직책으로 변경
- **자기소개**: 히어로 섹션 및 About 섹션의 설명 텍스트 수정
- **연락처**: 이메일, 전화번호, 위치 정보 입력
- **스킬**: 실제 보유 기술과 숙련도(%) 입력
- **경력**: 실제 회사명, 기간, 업무 내용 입력
- **학력**: 실제 학교명, 전공, 졸업년도 입력
- **프로젝트**: 프로젝트명, 설명, GitHub 링크, 데모 링크 입력
- **소셜 링크**: LinkedIn, Instagram 링크 입력

## 이미지 업로드 방법

`images/` 폴더에 아래 파일명으로 사진을 추가하세요:
- `profile.jpg` — 히어로 섹션 원형 프로필 사진
- `about.jpg` — 소개 섹션 사진 (세로형 권장)
- `project1~3.jpg` — 프로젝트 썸네일 이미지

## 로컬 실행

별도 서버 없이 `index.html`을 브라우저에서 직접 열면 됩니다.
